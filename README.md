# 클래스 인사이트 — 영어 평가 도우미

- 학번: 미입력
- 이름: 미입력
- 배포 URL: 배포 후 입력

## 실행

Python 3.13 환경에서 다음 명령으로 실행합니다.

```bash
pip install -r requirements.txt
streamlit run app.py
```

`서비스 소개`와 `성적 분석` 두 페이지로 구성되어 있습니다. 성적 분석 페이지 왼쪽에서 **문제지 PDF, 정답·배점 PDF, OMR xlsx/csv**를 각각 올리고 `분석 시작`을 누르세요. API 키가 없어도 채점·엑셀 다운로드는 가능합니다. 채팅은 화면에서 API 키를 입력하거나 서버의 `OPENAI_API_KEY` 환경변수/Streamlit Secrets를 설정하면 사용할 수 있습니다.

OMR 첫 행은 `학생명, Q01, Q02, …` 형식입니다. 고유한 학생 이름/번호를 사용하며 응답은 1~5 또는 ①~⑤입니다. 빈칸·0·미응답은 오답으로 계산합니다. 문항 누락, 중복 학생, 잘못된 응답 값은 오류로 안내합니다. 임의의 학생 수로 작동하며 원본 예시의 실제 학생 수를 그대로 읽습니다.

## 구현

- `grading.py`: PDF에서 문항 번호·정답·배점을 런타임에 읽고 Python으로 점수, 평균, 중앙값, 전체 학생 기준 표준편차(ddof=0), 문항별 오답 인원을 계산합니다. 정답/배점/학생 점수는 하드코딩하지 않았습니다.
- `assistant.py`: 수업의 `@tool`, `create_agent`, LangChain 메시지 형식을 사용합니다. 계산된 결과를 먼저 전달해 불필요한 도구 왕복을 줄이고, 추가 문항은 도구로 조회합니다. 문제 생성에는 수업의 Pydantic·`with_structured_output`을 사용하고, 정답을 가린 독립 검토로 유일한 정답과 원문 유형을 확인합니다. `gpt-5.4-mini`를 사용하며 문제 작성에만 추론을 설정합니다. 어휘 문제는 정상 지문에서 표시한 단어 하나만 바꿔 구성합니다.
- `app.py`: Streamlit 두 페이지, 개별 파일 업로드, 채점 후 엑셀·채팅 활성화, 세션 대화 기억을 구현합니다. 자료를 바꾸면 이전 결과와 대화를 초기화합니다.
- 다운로드 엑셀: `전체 성적 개요`, `학생별 성적`(점수와 문항별 O/X), `문항별 분석`, `학생 응답`을 포함합니다. 오답 상위 3개는 오답 인원 내림차순, 동률이면 문항 번호 순입니다. 최저점 학생은 동점자를 모두 반환합니다.
- 없는 학생·출결 등 미제공 정보는 확인할 수 없다고 답합니다. 내부 도구·프롬프트·키 공개 요구는 거부합니다. 웹 검색·임의 코드 실행 도구는 없습니다. API 키와 학생 파일을 저장소에 포함하지 않습니다.
- 채팅의 전체 처리에 18초 제한을 둡니다. 외부 API 상황에 따라 지연/실패할 수 있으며, 시간 제한으로 중단된 응답을 정상 답변으로 취급하지 않습니다.

원본 파일은 메모리에서 읽으며 수정·변환·재저장하지 않습니다. 시험지는 텍스트가 있는 2단 객관식 PDF, 정답지는 문항·정답·배점 3개 열이 반복되는 표를 지원합니다. 이미지뿐인 스캔 PDF/OCR은 지원하지 않습니다. 듣기 음원이 제공되지 않아 원래 듣기 대본은 추측하지 않고 유사 문제의 새로운 대본을 생성합니다.

## 수업 자료 반영

바탕화면 `부캠`의 6개 PDF와 이전에 제공한 실습 노트북을 참고했습니다.

| 자료 | 반영한 내용 |
| --- | --- |
| Streamlit.pdf | 30·33쪽의 `st.Page`/`st.navigation`, 47~53쪽 채팅과 `st.session_state`, GitHub 기반 배포 흐름 |
| Day1_LangChain.pdf | 47쪽 구조화된 응답, 56~57쪽 `@tool`/`create_agent`, 67쪽 시스템 프롬프트 |
| LangGraph.pdf | 모델과 도구를 연결하고, 도구 결과를 메시지로 반환하는 흐름 |
| LangGraph_Adv.pdf | 생성 → 평가 → 수정의 흐름과 반복 상한, 구조화된 평가 결과 |
| RAG_Basic.pdf / 3_RAG_Adv.pdf | 원문을 검색/조회한 뒤 근거에 따라 답변하고 생성 품질과 시간을 구분해 검증하는 원칙 |

문항 번호로 원문을 정확히 조회할 수 있어 불필요한 임베딩·벡터 검색은 추가하지 않았습니다. `create_agent`의 도구 호출 흐름과 세션 메시지로 구성하며, 별도의 복잡한 그래프나 대화 DB는 필요하지 않습니다.

## 배포 및 제출

1. 이 폴더를 GitHub `rrrriinnn/Test-Agent` 저장소에 커밋하고 푸시합니다. 학생 파일과 실제 API 키는 업로드하지 마세요.
2. [Streamlit Community Cloud](https://share.streamlit.io/)에서 해당 저장소·브랜치와 진입 파일 `app.py`를 선택합니다. Python 3.13을 사용합니다.
3. 앱 설정의 Secrets에 아래처럼 실제 키를 별도로 설정합니다. 아래 값은 예시이며 작동하는 키가 아닙니다.

   ```toml
   OPENAI_API_KEY = "발급받은 키"
   ```

4. 위의 학번·이름·실제 배포 URL을 입력합니다.
5. 과제 안내에 따라 저장소 Settings → Collaborators에서 교수자 `jaypakdevkr`를 초대하고 배포 URL과 함께 제출합니다. 서비스는 11월 11일 23:59까지 유지해야 합니다.

현재 README의 미입력 항목과 배포 URL은 실제 정보가 확인되면 채워야 합니다.
