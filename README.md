# 클래스 인사이트 — 영어 평가 도우미

- 학번: 미입력
- 이름: 미입력
- 배포 URL: 배포 후 입력

## 실행

Python 3.13 환경에서 다음 명령으로 실행합니다.

```bash
pip install -r requirements.txt
streamlit run app.py
```

`서비스 소개`와 `챗봇` 두 페이지로 구성되어 있습니다. 화면 맨 위의 가로 버튼 두 개로 페이지를 이동합니다. 챗봇 페이지 왼쪽 사이드바에서 **문제지 PDF, 정답·배점 PDF, OMR xlsx/csv**를 각각 올리고 `분석 시작`을 누르세요. API 키가 없어도 채점·엑셀 다운로드는 가능합니다. 채팅은 화면에서 API 키를 입력하거나 서버의 `OPENAI_API_KEY` 환경변수/Streamlit Secrets를 설정하면 사용할 수 있습니다.

OMR 첫 행은 `학생명, Q01, Q02, …` 형식입니다. 고유한 학생 이름/번호를 사용하며 응답은 1~5 또는 ①~⑤입니다. 빈칸·0·미응답은 오답으로 계산합니다. 문항 누락, 중복 학생, 잘못된 응답 값은 오류로 안내합니다. 임의의 학생 수로 작동하며 원본 예시의 실제 학생 수를 그대로 읽습니다.

## 구현

- `grading.py`: PDF에서 문항 번호·정답·배점을 런타임에 읽고 Python으로 점수, 평균, 중앙값, 전체 학생 기준 표준편차(ddof=0), 문항별 오답 인원을 계산합니다. 정답/배점/학생 점수는 하드코딩하지 않았습니다.
- `grade_facts.py`: 학생의 개별 문항 정오·응답·획득 점수, 정답/오답 문항 목록을 실제 OMR과 정답으로 직접 조회합니다. 인식한 성적 질의는 LLM을 거치지 않고 확정된 값을 그대로 답합니다. 모호한 정오 질의는 학생 식별자를 확인하도록 안내합니다.
- `assistant.py`: 수업의 `@tool`, `create_agent`, LangChain 메시지 형식을 사용합니다. 계산된 결과를 먼저 전달하고, 추가 문항은 도구로 조회합니다. Pydantic·`with_structured_output`으로 새 문제를 작성하고 정답을 가린 독립 풀이에서 유형·정답·의도하지 않은 문법 오류를 검사합니다. 어휘 문제는 정상 지문에서 단어 하나만 바꿉니다. 도표 문제는 새로운 표를 만든 뒤 Python이 다섯 보기를 계산하여 정확히 하나만 틀리게 구성합니다.
- 기본 대화·문제 작성은 `gpt-5.4-mini`, 원본 그림·도표 조회는 `gpt-5.4`를 사용합니다. 문항 번호로 그림·도표를 질문하면 해당 원본 이미지도 함께 참조합니다.
- `api_errors.py`: 잔액·사용 한도, 요청 속도 제한, 인증, 연결 및 서버 오류를 구분해 안내합니다.
- `app.py`: Streamlit 두 페이지, 개별 파일 업로드, 채점 후 엑셀·채팅 활성화와 세션 기억을 구현합니다. 페이지를 오가도 원본 업로드·API 키·대화를 유지합니다. 파일을 교체하면 이전 결과와 대화를 지우며, `자료·대화 초기화` 버튼으로 보관 자료를 비울 수 있습니다.
- 다운로드 엑셀: `전체 성적 개요`, `학생별 성적`(점수와 문항별 O/X), `문항별 분석`, `학생 응답`을 포함합니다. 오답 상위 3개는 오답 인원 내림차순, 동률이면 문항 번호 순입니다. 최저점 학생은 동점자를 모두 반환합니다.
- 없는 학생·출결 등 미제공 정보는 확인할 수 없다고 답합니다. 내부 도구·프롬프트·키 공개 요구는 거부합니다. 웹 검색·임의 코드 실행 도구는 없습니다. API 키와 학생 파일을 저장소에 포함하지 않습니다.
- 채팅의 전체 처리에 18초 제한을 둡니다. 외부 API 상황에 따라 지연/실패할 수 있으며, 시간 제한으로 중단된 응답을 정상 답변으로 취급하지 않습니다.

원본 파일은 메모리에서 읽으며 파일을 덮어쓰거나 재저장하지 않습니다. 문제지의 열을 넘어가는 공통 지시문·지문을 함께 보존하고, 그림·도표 문항은 원본을 메모리에서 참조 이미지로 렌더링합니다. 시험지는 텍스트가 있는 2단 객관식 PDF, 정답지는 문항·정답·배점 3개 열이 반복되는 표를 지원합니다. 이미지뿐인 스캔 PDF 전체의 OCR은 지원하지 않습니다. 듣기 음원·실제 대본이 제공되지 않아 원본 대화는 확인할 수 없다고 답하고, 요청하면 새 연습용 대본을 생성합니다.

검증의 기준·발견한 오류·수정·재검사 결과와 남은 제출 항목은 [검증결과.md](검증결과.md)에 기록했습니다.

## 파일 불일치 처리

- **채점 차단:** 문제지·정답표·OMR의 문항 번호 집합 불일치, 중복 문항/응답 열, 누락 열, 허용 범위를 벗어난 응답. 누락·추가 번호를 표시하며 이전 결과도 지웁니다.
- **경고 후 계산:** 학년도·과목·시험명·홀수/짝수형 표기가 서로 다른 경우. 화면과 다운로드 엑셀에 주의 문구를 남깁니다.
- OMR에 시험 식별 정보가 없으면, 문항 번호가 같아도 동일 시험인지는 자동으로 확정할 수 없다고 안내합니다. 점수가 낮다는 이유만으로 다른 시험이라고 판단하지 않습니다.
- 검증셋의 학생별 응답은 로컬 `검증자료` 폴더에 보관하며 Git 추적 대상에서 제외합니다. 앱은 이 검증셋을 읽거나 답변에 사용하지 않습니다.

| Day1_LangChain.pdf | 47쪽 구조화된 응답, 56~57쪽 `@tool`/`create_agent`, 67쪽 시스템 프롬프트 |

문항 번호로 원문을 정확히 조회할 수 있어 불필요한 임베딩·벡터 검색은 추가하지 않았습니다. `create_agent`의 도구 호출 흐름과 세션 메시지로 구성하며, 별도의 복잡한 그래프나 대화 DB는 필요하지 않습니다.

   OPENAI_API_KEY = "발급받은 키"
